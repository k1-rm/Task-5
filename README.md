# Task-5
In this task, I implemented both Decision Tree and Random Forest classifiers using the Heart Disease dataset. The code follows a step-by-step structure that begins with loading and preparing the data, followed by training a basic decision tree model. To prevent overfitting, I also trained a pruned version of the tree with limited depth. I then built a Random Forest ensemble to compare performance, evaluated using accuracy, classification reports, and confusion matrices. Cross-validation was performed to ensure model stability, and feature importances from the random forest were visualized to understand which variables contribute most to predictions. The task demonstrated key concepts of tree-based learning, including overfitting control, ensemble learning, and interpretability.
